# ABC Hospital Virtual Appointment System

## Project Overview
A web-based hospital appointment management system designed to help patients request appointments online and make the appointment process more convenient.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Key Features
- Online appointment requests.
- Patient information management.
- Appointment scheduling.
- User-friendly interface.
- Database integration.

## Project Objectives
- Simplify the hospital appointment process.
- Reduce manual appointment handling.
- Improve accessibility for patients.
- Apply web development and database management concepts.

## Repository Contents
This repository contains the project source code, database-related files and other resources.

## How to Run
1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL.
4. Import the project database into phpMyAdmin, if required.
5. Open `http://localhost/abc_hospital_virtual_appointment/` in your browser.
